#Web Pages Created to Match Reference Images

## Overview
The purpose of this project was to create a website design that matches specifications provided by a fictional client.<br>
The directory "Original-Design-Documentation" contains the design brief in "Summary of page design.txt" and references photos for each of the requested pages.<br>
Fonts and images to be used on the site were supplied and are stored in Fonts/Roboto and Images respectively.<br>
The html and css files in the root folder are the final results of my work creating the website desired by the client according to the specification.<br>
The directory "Photos-of-final-product" contains screenshots of the final website design created to match the design brief.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://web-pages-created-to-match-referenc.vercel.app/

## Tech Stack
- HTML5
- CSS3
